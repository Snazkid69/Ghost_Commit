# Ghost_Commit
An AI-powered Git workflow and semantic commit assistant for Linux developers that analyzes staged diffs and generates conventional commit messages.
👻 GhostCommit

> **An AI-powered Git workflow and semantic commit assistant for Linux developers that analyzes staged diffs and generates conventional commit messages.**

---

## 🚀 Features

* **🔍 Smart Diff Inspection:** Safely reads your cached/staged git diffs and repository status.
* **🤖 Gemini-Powered Analysis:** Leverages Google Gemini (`gemini-2.5-flash`) to analyze code changes and write precise, conventional commit messages.
* **💡 Code Quality & Hygiene Review:** Flags potential bugs, missing tests, or security oversights before your code gets committed.
* **⚡ Native Linux CLI:** Built specifically for Linux terminal users using `Rich` for gorgeous dashboards and `Click` for clean command-line options.
